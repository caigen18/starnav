# 🧭 星遇导航 StarNav

一个很酷的交互式网址导航站 —— 星空粒子背景、鼠标聚光灯、3D 倾斜卡片、实时时钟问候。
纯前端 UI + 轻量 Node.js 后端（零依赖），**真正的服务端鉴权**：密码哈希、HttpOnly 会话、只读内容由服务器强制保护。

## 🚀 快速开始

```bash
node server.js
# 然后浏览器打开 http://localhost:3000
```

无需 `npm install`（零依赖，仅用 Node 内置模块）。**注意：不能再直接双击 `index.html`**，必须通过服务器访问，数据存储在服务器的 `data.json`。

> 首次运行：服务器数据为空时，浏览器会自动用 208 个内置站点完成初始化（AI 助手 / 开发工具 / 设计灵感 / 学习资源 / 娱乐影音 / 效率办公 / 币圈 / 全球 Top 100 / 中国 Top 50，内置站点带只读标记）。**建议首次初始化由管理员在自己浏览器完成**；老数据升级时，新增的内置分类与站点会自动按 URL 去重合并，不会重复添加。

## 🔒 权限模型（服务端强制）

| 内容 | 普通用户 | 管理模式（授权人员） |
| --- | --- | --- |
| 内置站点（🔒 只读） | 仅浏览、搜索、复制、计热度 | 可编辑 / 删除 / 调整顺序 / 取消只读 |
| 自己添加的站点 | 完全可编辑 | 完全可编辑 |
| 页面（含只读内容） | 不能删除 | 可删除 |

- 🔑 **管理模式入口是隐藏的**：普通访问看不到「管理模式」按钮；只有访问指定网址 **`http://localhost:3000/?admin=starnav`**（地址栏带密钥参数）时顶栏才出现锁按钮；
- **服务端安全**：密码以 scrypt 哈希存于服务器 `data.json`（**持久化保存，普通数据保存/服务器重启都不会丢失**，只能通过「修改管理密码」更改）；登录后签发 `HttpOnly + SameSite` Cookie 会话（7 天有效，**会话同样持久化，重启服务器不丢**）；非授权请求写入数据时，服务器会**强制还原只读内容**（篡改、删除、新增只读标记都会被驳回）；
- 首次点击锁按钮会引导设置管理密码；已授权时弹窗内可「修改管理密码」「退出管理模式」；
- 密钥 `ADMIN_TOKEN` 在 `js/app.js` 顶部、`server.js` 可另行设置环境变量，可改成更隐蔽的字符串；
- ⚠️ 说明：地址栏密钥只是"隐藏入口"，真正的防线在服务端；服务器文件若被他人直接访问/修改则无法防御（可自行限制端口访问、使用 HTTPS 反向代理）。

## 📁 项目结构

```
网站/
├── server.js       # Node 后端（零依赖）：静态服务 + 鉴权 API + 服务端存储
├── index.html      # 页面结构
├── css/style.css   # 视觉与动画（星空 / hao123 经典双主题）
├── js/app.js       # 前端交互（通过 API 与服务器同步）
├── data.json       # 运行后自动生成：站点数据 + 密码哈希（勿外传）
└── README.md
```

## 🔌 API 一览

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/session` | 查询当前会话（是否授权 / 是否已设密码） |
| POST | `/api/setup` | 首次设置管理密码（仅一次） |
| POST | `/api/login` | 密码登录，签发 HttpOnly 会话 Cookie |
| POST | `/api/logout` | 退出登录 |
| POST | `/api/password` | 修改密码（需授权会话） |
| GET | `/api/data` | 拉取全部数据 |
| PUT | `/api/data` | 保存数据（非授权请求自动执行只读合并校验） |

## ⌨️ 快捷键

- `/` 或 `Ctrl+K` — 聚焦搜索框
- `Enter`（搜索时）— 打开第一个匹配结果
- `Esc` — 关闭弹窗 / 清空搜索 / 取消聚焦
- 卡片中键点击 — 新标签页打开

## 🛠️ 进阶

- 添加站点时「图标」留空会自动抓取站点 favicon，失败则回退为渐变文字头像；
- 也可以手动填表情符号（如 🐳）或图片网址作为图标；
- 分类输入框支持选择已有分类，或直接输入创建新分类；
- 更换端口：`PORT=8080 node server.js`。

## 📊 流量统计（本地，不入库）

统计代码放在 `js/analytics.local.js`——该文件已加入 `.gitignore`，**不会上传到 GitHub**（防止站点 ID 泄露、避免污染公开仓库）。

- 接入 / 更换统计：编辑 `js/analytics.local.js` 里的统计初始化参数即可；
- 移除统计：删除该文件，并删掉 `index.html` 末尾对应的一行 `<script src="js/analytics.local.js"></script>`；
- 注意：新克隆的仓库里没有此文件，统计不会生效——这是预期行为（统计只在你的本地部署上运行）。
